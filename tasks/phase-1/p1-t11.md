# infra(saascript-auth-service): Containerize SaaScript Auth Microservice

**1. Rationale:**
Containerizing the Authentication Microservice (`auth_service`) is essential for achieving a portable, consistent, and scalable development and deployment environment, aligning with the principles of microservices architecture. By creating a Dockerfile and integrating the auth service into the `infra/docker-compose.yml` setup, we ensure that it can be run reproducibly across different developer machines and operate independently within the local Dockerized environment. This mirrors our commitment to best practices by simplifying local development and ensuring services can interoperate within the defined infrastructure, as outlined in `architecture.md` (Section 2.2: Containerization) and `local-development.md`.

**2. Goal:**
To create a Dockerfile for the `saascript-auth-service`, build its Docker image, and integrate it into the `infra/docker-compose.yml` file. The containerized auth service should start successfully via Docker Compose, expose its necessary ports, and respond to HTTP requests, demonstrating its ability to operate within the local Dockerized environment.

**3. Detailed Steps:**
* Step 1: **Navigate to the Auth Microservice Directory.**
    Ensure your current working directory is `modules/auth_service/`.
* Step 2: **Create `Dockerfile` for the Auth Microservice.**
    Create a `Dockerfile` in the `modules/auth_service/` directory. This Dockerfile will define the steps to build a Docker image for the NestJS Authentication Microservice, including dependencies, build process, and runtime environment.
* Step 3: **Update Auth Microservice `package.json` for Docker Compatibility.**
    Review and potentially adjust `modules/auth_service/package.json` scripts to ensure they are compatible with the Docker build process (e.g., `build` script correctly outputs to `dist/`). Ensure the `start:prod` script uses the compiled JavaScript.
* Step 4: **Add Auth Microservice to `infra/docker-compose.yml`.**
    Navigate to the monorepo root and open `infra/docker-compose.yml`. Add a new service definition for `saascript-auth-service` that builds from the `modules/auth_service/` Dockerfile, exposes its port (e.g., 3001), and defines its dependencies on infrastructure services (e.g., PostgreSQL, Redis, RabbitMQ if needed for its initial operations).
* Step 5: **Install Monorepo Dependencies (Again).**
    After modifying `infra/docker-compose.yml` and potentially `modules/auth_service/package.json`, execute `yarn install:all` at the monorepo root to ensure all dependencies are correctly handled and linked.
* Step 6: **Build and Run All Docker Compose Services.**
    Bring down the existing infrastructure services and bring them back up, including the newly added `saascript-auth-service`. This will trigger the Docker image build for the auth service.
* Step 7: **Verify Containerized Auth Microservice Accessibility.**
    Once the services are up, verify that the containerized Auth Microservice is running and accessible by navigating to its default local port (`http://localhost:3001`) in your browser or with `curl`. You should receive the "Hello from SaaScript Auth Microservice!" message.
* Step 8: **Document Containerization.**
    Update `docs/local-development.md` and `docs/architecture.md` to reflect the containerization of the Authentication Microservice, detailing its Dockerfile and its integration into the Docker Compose setup.
