# chore(saascript-libs-database): Create Shared PostgreSQL Database Module

**1. Rationale:**
In a microservices architecture, establishing a shared, reusable library for common functionalities like database connectivity is a fundamental best practice. This task explicitly defines the creation of a dedicated NestJS module within `modules/libs/database/postgres/`. This module will encapsulate the common PostgreSQL connection logic, TypeORM setup, and configuration management. By centralizing this, we avoid code duplication across services, ensure consistent database interaction, simplify future updates, and adhere to the "Don't Repeat Yourself (DRY)" principle, which is critical for the maintainability and scalability of the SaaScript monorepo. This module must be in place before individual microservices attempt to connect to the PostgreSQL database.

**2. Goal:**
To successfully create a shared NestJS module (`PostgresModule`) within `modules/libs/database/postgres/` that provides robust PostgreSQL database connectivity using TypeORM. This includes setting up its dedicated project structure, installing necessary database-related dependencies, configuring TypeORM via environment variables, and ensuring the module is correctly recognized as a Yarn workspace within the monorepo, ready for injection into individual microservices.

**3. Detailed Steps:**
* Step 1: **Navigate to the `modules/libs/database/` Directory.**
    Ensure your current working directory is `modules/libs/database/` at the monorepo root. Create this directory if it doesn't exist.
* Step 2: **Create the `postgres/` Module Directory.**
    Create the `postgres/` directory inside `modules/libs/database/`. This will be the root for the shared PostgreSQL database module.
* Step 3: **Initialize Node.js Project and Install Dependencies.**
    Initialize a new Node.js project within `modules/libs/database/postgres/`. Install TypeORM, the `pg` (PostgreSQL) driver, `@nestjs/typeorm`, and `@nestjs/config` (for environment variable management within NestJS), along with TypeScript dev dependencies.
* Step 4: **Create `tsconfig.json` for the PostgreSQL Module.**
    Create a `tsconfig.json` file inside `modules/libs/database/postgres/` to configure TypeScript compilation for this shared library.
* Step 5: **Create `src/` Directory and PostgreSQL Module File (`postgres.module.ts`).**
    Create the `src/` directory within `modules/libs/database/postgres/` and then the `postgres.module.ts` file. This will contain the NestJS module that sets up and provides the TypeORM connection to PostgreSQL, leveraging `ConfigModule` for dynamic configuration.
* Step 6: **Create TypeORM Configuration File (Optional but Recommended for CLI).**
    Consider creating a `ormconfig.ts` or similar file in the root of `modules/libs/database/postgres/` if TypeORM CLI will be used for migrations/schema generation directly from this module.
* Step 7: **Update PostgreSQL Module `package.json` Scripts.**
    Modify the `package.json` within `modules/libs/database/postgres/` to include necessary scripts, particularly `build`, and potentially `typeorm` CLI commands if step 6 is implemented.
* Step 8: **Update Monorepo Root `package.json` Workspaces.**
    Add `modules/libs/database/postgres` to the `workspaces` array in the monorepo's root `package.json` (`saascript/package.json`) to ensure Yarn recognizes this new shared module.
* Step 9: **Install Monorepo Dependencies.**
    Execute `yarn install:all` at the monorepo root to ensure all new dependencies for the PostgreSQL module are installed and cross-linked correctly within the monorepo.
* Step 10: **Build the PostgreSQL Database Module.**
    Build the newly created `saascript-libs-database-postgres` module to ensure it compiles correctly.
* Step 11: **Document the Shared PostgreSQL Module.**
    Update `docs/architecture.md` (specifically under "Data Persistence" and "Module Design Principles") and `docs/microservices.md` (or a dedicated `docs/libraries.md` if preferred) to detail the creation and purpose of this shared PostgreSQL database module. Include guidance on how other microservices will import and utilize it.

* [ ] The monorepo root `package.json`'s `workspaces` array includes `modules/libs/database/postgres`.
