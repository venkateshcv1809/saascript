# chore(saascript-modules-projects): Setup Testing Framework for Project Service

**1. Rationale:**
Establishing a robust and comprehensive testing framework for the new `saascript-modules-projects` microservice is crucial for ensuring its reliability, maintainability, and correct behavior. This task specifically configures the testing environment and necessary tooling (Jest for unit/integration testing, Supertest for HTTP assertions, and code coverage reporting). Implementing this early enables Test-Driven Development (TDD) practices, allows for immediate validation of project management logic, catches regressions proactively, and aligns with the project's commitment to best practices and high-quality code. This mirrors the testing setups for other core services established in Phase 1 (P1-T13, P1-T14).

**2. Goal:**
To successfully install and configure the Jest testing framework, `ts-jest` for TypeScript support, and `supertest` for HTTP request testing within the `modules/modules/projects/` service. This includes creating and configuring `jest.config.js` and a basic unit test file for `AppController` (`app.controller.spec.ts`), ensuring the test runs successfully and reports code coverage.

**3. Detailed Steps:**
* Step 1: **Navigate to the Project Microservice Directory.**
    Ensure your current working directory is `modules/modules/projects/`.
* Step 2: **Install Testing Dependencies.**
    Install Jest, `@types/jest`, `ts-jest`, and `supertest`, and `@types/supertest` as development dependencies within the `modules/modules/projects/` project.
* Step 3: **Create and Configure `jest.config.js`.**
    Create a `jest.config.js` file in the `modules/modules/projects/` directory. This file will configure Jest for unit and integration testing, including TypeScript transformation and code coverage settings.
* Step 4: **Create Basic Unit Test File.**
    Create a basic unit test file (e.g., `src/app.controller.spec.ts`) for the `AppController` within `modules/modules/projects/src/`. This test should verify the basic functionality of the controller's endpoint (e.g., the "Hello from SaaScript Project Management Service!" response).
* Step 5: **Update Project Service `package.json` Test Scripts.**
    Verify or modify the `test` scripts in `modules/modules/projects/package.json` to correctly execute Jest tests and generate code coverage reports.
* Step 6: **Install Monorepo Dependencies.**
    After installing new dev dependencies in `modules/modules/projects/`, execute `yarn install:all` at the monorepo root to ensure all dependencies are correctly linked within the monorepo.
* Step 7: **Run Project Service Tests and Verify Coverage.**
    Execute the test script for the `saascript-modules-projects` service. Verify that the unit tests run successfully and that code coverage reports are generated as expected.
* Step 8: **Document Testing Setup for Project Service.**
    Update `docs/local-development.md` and `docs/development-workflow.md` to include guidance on running tests specifically for the Project Management Microservice.
