# chore(saascript-libs-messaging): Create Shared RabbitMQ Messaging Module

**1. Rationale:**
To facilitate consistent and efficient asynchronous communication across the SaaScript microservices, a shared and reusable NestJS module for RabbitMQ messaging is essential. This task focuses on developing `modules/libs/messaging/rabbitmq/`, which will encapsulate common RabbitMQ client configuration, connection management, and basic producer/consumer boilerplate. By centralizing this logic, we ensure standardized messaging patterns, reduce code duplication in individual services, and simplify future integrations, aligning with the project's best practices for modularity and maintainability. This module is a prerequisite for any microservice needing to publish or consume messages via RabbitMQ.

**2. Goal:**
To successfully create a shared NestJS module (`RabbitMQModule`) within `modules/libs/messaging/rabbitmq/` that provides robust RabbitMQ client connectivity. This includes setting up its dedicated project structure, installing necessary messaging-related dependencies, configuring the client via environment variables, and ensuring the module is correctly recognized as a Yarn workspace within the monorepo, ready for injection into individual microservices.

**3. Detailed Steps:**
* Step 1: **Navigate to the `modules/libs/messaging/` Directory.**
    Ensure your current working directory is `modules/libs/messaging/` at the monorepo root. Create this directory if it doesn't exist.
* Step 2: **Create the `rabbitmq/` Module Directory.**
    Create the `rabbitmq/` directory inside `modules/libs/messaging/`. This will be the root for the shared RabbitMQ messaging module.
* Step 3: **Initialize Node.js Project and Install Dependencies.**
    Initialize a new Node.js project within `modules/libs/messaging/rabbitmq/`. Install the `amqplib` (RabbitMQ client library), `@nestjs/config` (for environment variable management), and other necessary NestJS/TypeScript dev dependencies.
* Step 4: **Create `tsconfig.json` for the RabbitMQ Module.**
    Create a `tsconfig.json` file inside `modules/libs/messaging/rabbitmq/` to configure TypeScript compilation for this shared library.
* Step 5: **Create `src/` Directory and RabbitMQ Module File (`rabbitmq.module.ts`).**
    Create the `src/` directory within `modules/libs/messaging/rabbitmq/` and then the `rabbitmq.module.ts` file. This will contain the NestJS module that sets up and provides the RabbitMQ connection, leveraging `ConfigModule` for dynamic configuration. It should aim to expose a connection factory or client instance.
* Step 6: **Update RabbitMQ Module `package.json` Scripts.**
    Modify the `package.json` within `modules/libs/messaging/rabbitmq/` to include necessary scripts, particularly `build`.
* Step 7: **Update Monorepo Root `package.json` Workspaces.**
    Add `modules/libs/messaging/rabbitmq` to the `workspaces` array in the monorepo's root `package.json` (`saascript/package.json`) to ensure Yarn recognizes this new shared module.
* Step 8: **Install Monorepo Dependencies.**
    Execute `yarn install:all` at the monorepo root to ensure all new dependencies for the RabbitMQ module are installed and cross-linked correctly within the monorepo.
* Step 9: **Build the RabbitMQ Messaging Module.**
    Build the newly created `saascript-libs-messaging-rabbitmq` module to ensure it compiles correctly.
* Step 10: **Document the Shared RabbitMQ Module.**
    Update `docs/architecture.md` (specifically under "Asynchronous Communication" and "Module Design Principles") and `docs/microservices.md` (or `docs/libraries.md` if existing) to detail the creation and purpose of this shared RabbitMQ messaging module. Include guidance on how other microservices will import and utilize it for sending and receiving messages.
