# chore(saascript-libs-messaging): Create Shared Kafka Messaging Module

**1. Rationale:**
To facilitate consistent and efficient event streaming across the SaaScript microservices, a shared and reusable NestJS module for Kafka messaging is essential. This task focuses on developing `modules/libs/messaging/kafka/`, which will encapsulate common Kafka client configuration, connection management, and basic producer/consumer boilerplate. By centralizing this logic, we ensure standardized event-driven patterns, reduce code duplication in individual services, and simplify future integrations, aligning with the project's best practices for modularity and maintainability. This module is a prerequisite for any microservice needing to publish or consume events via Kafka.

**2. Goal:**
To successfully create a shared NestJS module (`KafkaModule`) within `modules/libs/messaging/kafka/` that provides robust Apache Kafka client connectivity. This includes setting up its dedicated project structure, installing necessary streaming-related dependencies (e.g., `kafkajs`), configuring the client via environment variables, and ensuring the module is correctly recognized as a Yarn workspace within the monorepo, ready for injection into individual microservices.

**3. Detailed Steps:**
* Step 1: **Navigate to the `modules/libs/messaging/` Directory.**
    Ensure your current working directory is `modules/libs/messaging/` at the monorepo root. This directory should have been created in P2-T4.
* Step 2: **Create the `kafka/` Module Directory.**
    Create the `kafka/` directory inside `modules/libs/messaging/`. This will be the root for the shared Kafka messaging module.
* Step 3: **Initialize Node.js Project and Install Dependencies.**
    Initialize a new Node.js project within `modules/libs/messaging/kafka/`. Install `kafkajs` (the Kafka client library), `@nestjs/config` (for environment variable management), and other necessary NestJS/TypeScript dev dependencies.
* Step 4: **Create `tsconfig.json` for the Kafka Module.**
    Create a `tsconfig.json` file inside `modules/libs/messaging/kafka/` to configure TypeScript compilation for this shared library.
* Step 5: **Create `src/` Directory and Kafka Module File (`kafka.module.ts`).**
    Create the `src/` directory within `modules/libs/messaging/kafka/` and then the `kafka.module.ts` file. This will contain the NestJS module that sets up and provides the Kafka client (producer and/or consumer instances), leveraging `ConfigModule` for dynamic configuration.
* Step 6: **Update Kafka Module `package.json` Scripts.**
    Modify the `package.json` within `modules/libs/messaging/kafka/` to include necessary scripts, particularly `build`.
* Step 7: **Update Monorepo Root `package.json` Workspaces.**
    Add `modules/libs/messaging/kafka` to the `workspaces` array in the monorepo's root `package.json` (`saascript/package.json`) to ensure Yarn recognizes this new shared module.
* Step 8: **Install Monorepo Dependencies.**
    Execute `yarn install:all` at the monorepo root to ensure all new dependencies for the Kafka module are installed and cross-linked correctly within the monorepo.
* Step 9: **Build the Kafka Messaging Module.**
    Build the newly created `saascript-libs-messaging-kafka` module to ensure it compiles correctly.
* Step 10: **Document the Shared Kafka Module.**
    Update `docs/architecture.md` (specifically under "Asynchronous Communication" and "Module Design Principles") and `docs/microservices.md` (or `docs/libraries.md` if existing) to detail the creation and purpose of this shared Kafka messaging module. Include guidance on how other microservices will import and utilize it for publishing and consuming events.
